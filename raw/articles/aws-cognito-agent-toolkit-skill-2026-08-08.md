- AWS 공식 공지: Amazon Cognito `aws-auth`가 Agent Toolkit for AWS의 core skill로 추가됨
- 기능 범위: user pool·app client·managed login·OAuth 2.0·token·JWT authorizer·passkey/WebAuthn·threat protection·Lambda trigger·identity pool 설정·보안 점검·troubleshooting
- AWS MCP Server 연동 agent는 IAM-based guardrail과 CloudTrail audit logging 아래 AWS CLI command를 실행한다는 공지 범위
- 원문은 agent approval UX, resource-level IAM policy, network boundary, region·price, production change safety를 확정하지 않으므로 조직별 검증 필요
