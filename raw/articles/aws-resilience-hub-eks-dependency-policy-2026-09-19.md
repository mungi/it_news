# AWS Resilience Hub adds three new capabilities

AWS는 2026년 9월 18일 Resilience Hub에 세 기능을 추가했다. EKS namespace 내부 label을 service input source로 지정해 failure mode analysis 대상 리소스를 기존 labeling convention에 맞출 수 있다. dependency discovery 활성화 고객은 생성형 AI 기반 dependency insights로 새 의존성, cross-Region dependency, unusual usage pattern을 확인할 수 있다. AWS Organizations를 통한 resilience policy 공유도 추가돼 중앙 팀이 여러 account에 policy를 적용하고 service별 적용 현황을 볼 수 있다. 차세대 Resilience Hub는 서울을 포함한 15개 리전에서 제공된다. 생성형 AI insight는 dependency graph의 사실을 대체하지 않으므로, EKS label 범위·cross-Region path·policy exception·RTO/RPO ownership을 실제 inventory와 drill evidence로 확인해야 함.
