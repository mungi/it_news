# Amazon CloudWatch Omni 8개 리전 확대

AWS What’s New RSS 원문을 기준으로 CloudWatch Omni의 리전 확대를 기록.

- 제공 확대: Canada (Central), Mumbai, Singapore, Sydney, Tokyo, Frankfurt, London, São Paulo 등 **8개 리전**
- 기능: 중앙 account의 space에서 AWS account·Region과 Azure·GCP telemetry 관측, service discovery·dependency mapping·golden metric surface 제공
- 탐색: chat·point-and-click·Agent Toolkit for AWS와 AWS DevOps Agent 기반 signal 탐색·dynamic view·root-cause 지원 범위
- Agent: LangGraph·CrewAI·OpenAI Agents SDK·Vercel AI SDK·Strands용 evaluation-driven workflow 명시
- 경계: ingestion completeness·cross-cloud identity·data residency·자동 root-cause 정확도·SLO 개선은 조직별 검증 대상
- 팀 액션: OpenTelemetry attribute·trace context·account/tenant identity·retention을 맞추고 원본 telemetry와 Omni view를 canary로 대조 필요
