# 베슬AI·네오AI 포항 AIDC GPU 플랫폼·시설 운영 경계

- 원문: https://www.aitimes.com/news/articleView.html?idxno=215327
- 원문 게시: 2026-09-16 12:15 KST

## 핵심 요약

- 베슬AI와 네오AI가 포항 AIDC 1·2센터 GPU 플랫폼·인프라 사업 협력 MOU 체결
- 포항 AIDC는 경북 40억원 출자 지역활성화 투자펀드 제9호 프로젝트이며, 총사업비 6,000억원·40MW GPU 기반 수냉식 AIDC 조성 목표
- 베슬AI는 GPU 플랫폼 구축·운영, GPU 할당·모니터링·스케줄링 담당
- 네오AI는 DC 설계·시공·인허가와 전력·냉각·통신·보안 기반시설 및 GPU 인프라 운영 담당
- source는 MOU·목표 규모를 다루며 GPU SKU·가용 용량·PUE·준공일·SLA는 확인하지 않음

- 실제 facility commissioning, GPU 설치 수량, 전력 인입, 서비스 가용성, tenant capacity와 SLA는 별도 계약·운영 증적으로 검증 필요
