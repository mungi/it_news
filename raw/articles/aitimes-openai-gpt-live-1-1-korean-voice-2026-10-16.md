# OpenAI `GPT-Live-1.1` 음성 업데이트 보도

- 범위: ChatGPT·Codex·개인용 AI 에이전트 `dots`의 음성 기능을 `GPT-Live-1.1`으로 갱신했다는 AI타임스 보도
- 언어: 한국어·프랑스어·독일어·힌디어·멕시코 스페인어·일본어의 새 음성과 언어별 억양 개선 범위
- UX: 응답 대기 중 `확인 중…` 표시의 대기와 반복 안내를 줄이고, 검색·정보 확인 중 짧은 진행 문구를 제공하는 범위
- 배포: ChatGPT Voice에 `GPT-Live-1.1`과 경량 `GPT-Live-1.1 Quip` 적용, API는 추후 제공 예정이라는 기사·OpenAI X 게시물 인용 범위
- 제한: 이용 가능한 음성은 지역·계정에 따라 다를 수 있으며, API 일정·음성 품질 지표·지원 국가 전체 범위는 해당 보도로 확정하지 않음

## 운영 경계

- 음성 agent 출시 검토 시 지원 언어 선언과 실제 계정·리전 entitlement, STT/TTS 품질, fallback, moderation·transcript retention을 분리 검증 필요
- 음성 모델 업데이트는 tool 권한, 사용자 승인, background action, 녹음·전사 데이터 처리의 보안 통제를 자동으로 변경하지 않음
