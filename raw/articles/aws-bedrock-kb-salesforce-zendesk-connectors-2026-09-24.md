# Amazon Bedrock Managed Knowledge Base now supports Salesforce and Zendesk as native data source connectors

AWS는 Amazon Bedrock Managed Knowledge Bases에 Salesforce와 Zendesk native data source connector를 추가했다고 발표했다. connector는 Salesforce knowledge article, Zendesk article과 community post를 managed knowledge base로 동기화하며, instance credential 제공 뒤 crawling·metadata extraction·incremental sync를 자동 처리하는 범위임. AWS는 customer-facing support bot과 internal sales enablement assistant를 예시로 제시함. source ACL mapping, delete propagation latency, tenant authorization, citation quality는 announcement에서 보장하지 않으므로 read-only least-privilege credential·data-class allowlist·sync freshness·retrieval authorization을 canary로 검증 필요.
