- AWS 공식 공지: AgentCore temporal policy와 rate limiting 추가
- temporal policy는 session prior action 문맥에서 workflow sequence, prior output binding, human approval, data freshness를 평가하는 범위
- rate limiting은 OAuth 또는 AWS IAM scope로 request, inference token, concurrent connection을 제어하는 범위
- session storage, cross-session behavior, latency, regional availability, price는 공지에서 확정되지 않음
