# Amazon CloudWatch Omni: AI-first observability for agents and applications

AWS는 2026년 9월 23일 CloudWatch의 발전형으로 Amazon CloudWatch Omni를 GA 공개했다. Omni는 OpenTelemetry 상호운용성과 CloudWatch의 운영 범위를 결합해 중앙 계정의 space에서 여러 AWS 계정·리전과 Azure workload telemetry를 함께 보도록 구성한다. 서비스와 dependency를 자동 발견하고 golden metric을 표시하며, natural-language chat·console guided path·AWS Agent Toolkit에서 telemetry를 조회하고 AWS DevOps Agent 기반 root-cause 지원을 제공한다. LangGraph·CrewAI·OpenAI Agents SDK·Vercel AI SDK·Strands agent workload에는 prompt·model call·tool invocation 별 평가와 experiment workflow를 제공한다. VS Code·Cursor·Kiro extension은 local agent instrumentation·debug·evaluation에 쓰이며 AWS account 없이도 사용할 수 있다. GA 리전은 US East (N. Virginia), US West (Oregon), Europe (Ireland)로 한정됨. cross-account·cross-region·Azure 관측과 AI-assisted root-cause 결과를 도입 전 access boundary, telemetry retention, false-positive, cost와 incident escalation ownership 기준으로 canary 검증 필요.
