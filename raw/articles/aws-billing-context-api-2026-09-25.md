# AWS Billing `ListBillingViewSegments` API

- 기간별 billing hierarchy·payer relationship·billable/pro forma rate setting context를 segment로 반환함.
- account migration과 Billing Conductor 변경 시 effective date range별 context를 조회하는 범위.
- cost·usage data는 반환하지 않으며 CUR·internal allocation·IAM approval을 대체하지 않음.
- 모든 AWS commercial Region에서 primary billing view 대상으로 추가 비용 없이 제공됨.
