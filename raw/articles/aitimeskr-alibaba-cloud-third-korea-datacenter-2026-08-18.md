## 직접 확인한 본문 사실

- 알리바바 클라우드가 국내 세 번째 데이터센터를 공식 출범한다고 기자간담회에서 밝혔다고 보도
- 기사 기준 2022년 첫 번째·2025년 두 번째 데이터센터 뒤 세 번째 시설을 개소
- 컴퓨팅·스토리지·네트워크·보안·데이터베이스·컨테이너·cloud-native 서비스 제공 계획
- 한국에서 AgentRun·STAROps·ACS Agent Sandbox·Agent Security Center·AI Security Guardrails 2.0·Agentic SOC 확대 계획 언급
- 이번 확장이 530억달러 AI 인프라 투자 계획의 일부이고 글로벌 인프라가 30개 리전·104개 AZ라는 기사 설명

## 증거 경계와 운영 메모

- 직접 확인한 출처는 인공지능신문 기사이며, 정확한 국내 위치·AZ mapping·서비스별 availability/SKU·quota/capacity·latency·DR topology·SLA·가격·support는 확인하지 않음
- 국내 데이터센터 개소 발표는 workload별 data residency·국외 이전·backup location·규제 적합성 또는 agent 서비스의 GA·권한·audit/data handling 보증이 아님
- 운영 action: service-specific console·계약·DPA 확인 뒤 representative workload의 latency·cross-region cost·failure recovery canary와 IAM·tool approval·egress·audit 검증 수행
