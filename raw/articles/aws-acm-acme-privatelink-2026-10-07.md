- managed ACME endpoint와 VPC interface endpoint로 private network path 구성
- account creation·order creation·domain validation·finalization·certificate retrieval 범위
- existing ACMEv2 client와 directory URL 변경 없이 Private DNS가 endpoint로 해석하는 구조
- ACM console·CloudTrail logging·CloudWatch metrics에서 activity 확인 범위
- all commercial AWS Regions 제공 및 standard AWS PrivateLink charge 적용 안내
