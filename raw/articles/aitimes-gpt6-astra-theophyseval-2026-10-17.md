# GPT-6 아스트라 TheoPhysEval 평가 보도

- AI타임스가 ICTS·타타 기초과학연구소·펜실베이니아대·Google DeepMind 등 35명 연구진의 TheoPhysEval 논문을 인용
- 검색·코드 실행 허용 조건에서 GPT-6 아스트라가 미공개 이론물리 문제 50개 중 49개 해결, 총 API 비용 116.28달러라는 기사 수치
- Claude Opus 5.5 46개, Gemini 3.8 Flash 34개, DeepSeek-V4.1 Flash 27개, GLM-5.3 21개라는 비교 결과
- 고전물리·양자장론·입자물리·중력·우주론 등 11개 분야에서 문헌 조건을 바꾸고 계산하는 문제 범위
- 기준 답안 재검토 과정에서 일부 전문가 계산 오류가 수정돼 최종 정답률 98%로 변경됐다는 기사 설명
- 미해결 난제 제외, 일부 출제자의 AI 도구 사용, 문제·정답 사전 노출 가능성의 완전 배제 불가라는 한계

## 운영 경계

검색 corpus, 코드 실행 환경, 모델·prompt 버전, 실행 artifact, grading·adjudication 이력을 보존하지 않으면 benchmark score를 재현 가능한 연구·도입 근거로 쓰기 어려움.
