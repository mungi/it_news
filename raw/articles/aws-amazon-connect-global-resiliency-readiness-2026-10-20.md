# Amazon Connect Global Resiliency readiness 화면

AWS What’s New 원문을 기준으로 연결 리전 전환 준비 상태 화면을 기록.

- Global Resiliency 페이지: 전체 readiness 상태와 native replication resource 목록 제공
- 상태: resource type별 in-sync·pending synchronization·action-needed 구분
- 예시: traffic distribution group과 연결되지 않은 phone number·user 식별 및 association 지원
- 범위: Customer Global Resiliency 지원 리전에서 제공
- 경계: 실제 traffic switch 성공, RTO/RPO, call routing·external integration·rollback은 별도 drill 검증 대상
- 팀 액션: 리전별 resource inventory와 switch rehearsal evidence를 운영 record로 유지
